## Aman Kansal

Senior Member of Technical Staff, Mobile — **TestMu AI** (formerly LambdaTest) · Noida, India

I build and own parts of TestMu AI's real-device cloud, the fleet of physical iOS and Android devices that teams use for manual and automated testing. My work covers the on-device agents in Swift, the Go services that run devices at fleet scale, and the design and review work that connects them across teams.

### Focus areas

- **iOS automation on real devices** — XCUITest, WebDriverAgent and Appium; keeping the fleet ready for each new iOS and Xcode release
- **Device capabilities** — image and audio injection, Apple Pay, accessibility and VoiceOver automation
- **Performance** — app profiling and metrics collection on real hardware
- **Fleet reliability** — automated device cleanup between sessions, failure analysis on production hosts
- **Platform tooling in Go** — device communication on [go-ios](https://github.com/danielpaulus/go-ios), test results, app re-signing
- **Engineering practice** — RFCs and technical design, code review across services, AI agents in the development workflow
